System Architecture & Quality Standards

The proposed system is engineered to solve operational bottlenecks in local community governance. It is designed and evaluated under strict software architecture standards:

Offline-First LAN & Docker Compose Orchestration

Operates completely offline on the office local network to bypass internet outages. The environment orchestrates isolated Docker containers (C# app server, PostgreSQL 16 database, Caddy proxy server) via Docker Compose, securing data privacy and ensuring zero external dependencies.

HTMX Server-Driven Reactivity

Avoids massive client-side JavaScript framework sizes. Powered by HTMX, the system performs lightning-fast DOM swaps using server-rendered HTML fragments, offering fluid single-page app (SPA) performance with virtually zero browser rendering overhead.

Optimistic Concurrency Control (OCC)

Prevents database write conflicts (such as "lost updates") when multiple admin staff edit the same resident profile or amortization log simultaneously. Leverages EF Core concurrency tokens (PostgreSQL `xmin` columns) to detect conflicts and rollback unsafe transactions automatically.

Automated Overdue Tracking Background Services

Utilizes background worker threads to automatically monitor equipment borrower slip logs, track return dates, and trigger delinquency alerts and overdue alerts without requiring manual staff checks.

Bulk Data Migration (Excel/CSV Parser)

Designed with a secure parser script that allows staff to import thousands of legacy resident profiles from Excel/CSV formats in seconds, performing database schema verification and duplicate detection automatically.
