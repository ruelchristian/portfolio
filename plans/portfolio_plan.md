# Plan - Portfolio Website Creation for Ruel Christian V. Umel

Create a visually stunning, high-performance, responsive single-page developer portfolio website showcasing Ruel Christian Umel's core skills, his PBV-III capstone project, and achievements. The design will utilize a premium, auto-adaptive (light/dark mode) glassmorphic theme with animated background "aurora" blobs, high-end hover states, and smooth scroll reveals.

## Scope

- **In**:
  - Semantic HTML structure (`index.html`) optimized for search engines (SEO).
  - Modern, responsive styling (`index.css`) featuring a premium adaptive theme (light/dark auto-detection and toggle) with frosted glass cards, glow effects, and moving aurora background animations.
  - High-end interactive elements (`index.js`) using standard JS and Anime.js (typing animations, magnetic element hover micro-interactions, scroll-reveal transitions).
  - Custom visual assets: A professional developer avatar/illustration and a realistic, premium dashboard mockup for the PBV-III Capstone project.
  - Interactive Project card for the PBV-III Capstone Project, displaying features, stack, and a mock browser window container.
  - A clean, modern Contact Section with micro-interactions and success animations.

- **Out**:
  - Direct copy-pasting of full CV sections (the CV will be used as background reference only; the copy will be concise and tailored for a portfolio).
  - Resume/CV download button (as per user instruction).
  - Framework dependencies (pure HTML/CSS/JS for high performance).
